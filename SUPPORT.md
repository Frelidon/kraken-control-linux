# Support

Kraken Control is an experimental community project and is not official NZXT software.

## Bug reports

Use the GitHub **Bug report** issue form. Include the Kraken Control version, Linux distribution/kernel, Kraken model/USB ID, relevant reviewed log excerpt and exact reproduction steps.

## New hardware

Use the **Hardware support request** issue form and attach a manually reviewed output from:

```bash
kraken-control-diagnostics
```

## Security problems

Do not publish exploitable security details in a normal issue. Follow [`SECURITY.md`](SECURITY.md).
